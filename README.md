# Cert Filter Ultra PRO

Фильтр сертификатов КриптоПро.

## Запуск
Для запуска приложения используйте скрипт `run.sh`:
```bash
./run.sh
```

## Перенос на другой компьютер
Чтобы перенести приложение на другой компьютер:

1. **Скопируйте папку** целиком на новый компьютер.
2. **Создайте виртуальное окружение** (внутри папки приложения):
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. **Установите права на исполнение**:
   ```bash
   chmod +x run.sh
   chmod +x hide_sertificate.desktop
   ```
4. **Ярлык**: Для удобства скопируйте `hide_sertificate.desktop` в `~/.local/share/applications/` на новом компьютере (при необходимости исправьте путь внутри файла).
