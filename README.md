# Cert Filter Ultra PRO

GUI-приложение для управления сертификатами (CryptoPro / CryptoAPI) на Linux и Windows.

## Возможности

- Просмотр и фильтрация сертификатов из хранилищ MY и AddressBook
- Быстрый поиск по CN (Common Name)
- Экспорт сертификатов в PFX (с закрытым ключом) и CER (без ключа)
- Импорт PFX-файлов
- Архивирование/распаковка сертификатов (скрытие/показ)
- Удаление сертификатов вместе с закрытыми ключами
- Редактирование Friendly Name
- Пакетный экспорт нескольких сертификатов в один PFX
- Сортировка по имени, дате начала/окончания действия

## Требования

### Linux
- **КриптоПро CSP** (библиотеки `libcapi10.so`, `libcapi20.so` в `/opt/cprocsp/lib/amd64/`)
- Python 3.8+
- PySide6

### Windows
- Установленный **КриптоПро CSP** или **VipNet CSP** (стандартные CryptoAPI провайдеры)
- Python 3.8+
- PySide6

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

### Linux
```bash
python cert_filter_ui.pyw
```
Рекомендуется использовать виртуальное окружение.

### Windows
```cmd
python cert_filter_ui.pyw
```
Или просто дважды кликните по файлу `cert_filter_ui.pyw` (если ассоциирован с Python).

## Использование

### 1. Выбор конфигурации
В левой панели выберите JSON-файл из выпадающего списка (например, `config_fl.json` или `config_ul.json`).

### 2. Быстрый фильтр
- Введите номер ключа в поле **КЛЮЧ** и нажмите **OK** — применится фильтр по CN из конфига
- Или нажмите на любую строку в **СПИСКЕ** — сразу фильтрует по выбранному значению

### 3. Работа со списком сертификатов (правая панель)
- **Поиск** — фильтрация по CN в реальном времени
- **Сортировка** — по имени, дате начала, дате окончания
- **Чекбоксы** — выберите несколько сертификатов для пакетного экспорта
- Кнопки строки:
  - `■` / `○` — скрыть/показать сертификат
  - `≡` — подробная информация и редактирование Friendly Name
  - `PFX` — экспорт в PFX (с паролем)
  - `CER` — экспорт в CER (без ключа)
  - `DEL` — удалить сертификат и закрытый ключ

### 4. Действия над всеми сертификатами (верхняя панель)
- **☑ Выбрать все / ☐ Снять все** — массовое выделение
- **Эксп. PFX** — экспорт отмеченных в один PFX-файл
- **Удал. выбранные** — удаление отмеченных сертификатов с ключами
- **Импорт PFX** — импорт PFX в хранилище
- **Показать все** — снять архивный флаг со всех
- **Скрыть все** — поставить архивный флаг на все

## Примечания

- На **Linux** работает через КриптоПро CSP (библиотеки `libcapi10.so`, `libcapi20.so`)
- На **Windows** работает через нативный CryptoAPI (`crypt32.dll`, `advapi32.dll`)
- Все операции с ключами выполняются через системное хранилище `MY` текущего пользователя
- На Windows не требуется дополнительная настройка путей к библиотекам
